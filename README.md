# 📚 سیستم مدیریت کتابخانه (Console)

یک اپلیکیشن کنسولی به زبان **Java 17** برای مدیریت کتابخانه.
در این مرحله داده‌ها در **حافظه** (ArrayList) نگهداری می‌شوند و دیتابیس نداریم؛
هدف این مرحله، پیاده‌سازی و دیدن منطق برنامه است.

> نکته: با بسته‌شدن برنامه، همه داده‌ها پاک می‌شوند.

## امکانات

**مدیریت کتاب‌ها**
- افزودن کتاب (عنوان، نویسنده، ISBN، سال انتشار) — ISBN تکراری مجاز نیست
- حذف کتاب (کتابِ امانت‌رفته قابل حذف نیست)
- جستجو بر اساس عنوان / نویسنده / ISBN
- نمایش همه کتاب‌ها همراه با وضعیت موجودی

**مدیریت اعضا**
- ثبت عضو جدید (نام، شماره تماس، ایمیل) — ایمیل تکراری مجاز نیست
- حذف عضو (عضوی که کتاب امانت دارد قابل حذف نیست)
- جستجو و نمایش اعضا

**امانت و بازگشت**
- امانت دادن کتاب به عضو — حداکثر ۳ کتاب هم‌زمان برای هر عضو
- دوره امانت: ۱۴ روز (امانت‌های دارای تأخیر در گزارش‌ها مشخص می‌شوند)
- بازگشت کتاب بر اساس شناسه کتاب

**گزارش‌ها**
- آمار کلی کتابخانه (تعداد کتاب‌ها، اعضا، امانت‌های فعال و تأخیردار)
- کتاب‌های در حال امانت
- امانت‌های دارای تأخیر
- تاریخچه امانت‌های هر عضو
- محبوب‌ترین کتاب‌ها (بیشترین تعداد امانت)

## ساختار پروژه (معماری لایه‌ای ساده)

```
library-management-system/
├── pom.xml                     # تنظیمات Maven
├── README.md
└── src/main/java/com/library/
    ├── Main.java               # نقطه شروع برنامه (متد main)
    ├── model/                  # مدل‌های داده (POJO)
    │   ├── Book.java
    │   ├── Member.java
    │   └── Loan.java
    ├── service/                # منطق برنامه (Business Logic)
    │   ├── BookService.java
    │   ├── MemberService.java
    │   ├── LoanService.java
    │   └── LibraryException.java
    └── ui/                     # رابط کاربری کنسولی
        └── ConsoleUI.java
```

- **model** — کلاس‌های داده‌ای ساده؛ هیچ منطقی ندارند و فقط داده را نگه می‌دارند.
- **service** — تمام منطق و قواعد (جستجو، اعتبارسنجی، امانت و...) اینجاست؛ لیست‌های ArrayList هم به‌صورت خصوصی داخل همین لایه نگهداری می‌شوند.
- **ui** — فقط منو، خواندن ورودی و نمایش خروجی؛ چیزی درباره نحوه ذخیره داده نمی‌داند.

## پیش‌نیازها

| ابزار | نسخه |
|-------|------|
| JDK | 17 یا بالاتر |
| Maven | 3.6 یا بالاتر (اختیاری — روش ۳ بدون Maven هم هست) |

## نحوه اجرا

در ریشه پروژه (پوشه‌ای که `pom.xml` در آن است) یکی از روش‌های زیر:

**روش ۱ — پیشنهادی (با Maven):**

```bash
mvn compile exec:java
```

**روش ۲ — کامپایل و اجرای دستی (با Maven):**

```bash
mvn compile
java -cp target/classes com.library.Main
```

**روش ۳ — بدون Maven (فقط JDK):**

```bash
# ویندوز (PowerShell)
javac -encoding UTF-8 -d target/classes src/main/java/com/library/*.java src/main/java/com/library/model/*.java src/main/java/com/library/service/*.java src/main/java/com/library/ui/*.java
java -cp target/classes com.library.Main

# لینوکس / مک / Git Bash
javac -encoding UTF-8 -d target/classes $(find src -name "*.java")
java -cp target/classes com.library.Main
```

همچنین می‌توانید پوشه پروژه را در IntelliJ IDEA (یا Eclipse) به‌عنوان پروژه Maven باز کنید و کلاس `Main` را اجرا کنید.

## داده نمونه

هنگام شروع برنامه چند کتاب و عضو نمونه بارگذاری می‌شود تا سریع بتوانید جستجو و امانت را تست کنید.
اگر نمی‌خواهید، فراخوانی `loadSampleData(...)` را از `Main.java` حذف کنید.

## گام بعدی (فاز ۲)

اتصال دیتابیس: چون داده‌ها فقط داخل کلاس‌های سرویس (ArrayList خصوصی) نگهداری می‌شوند،
می‌توان بدون تغییر رابط کاربری، ذخیره‌سازی را به دیتابیس (مثلاً H2 + JDBC یا SQLite) منتقل کرد.
